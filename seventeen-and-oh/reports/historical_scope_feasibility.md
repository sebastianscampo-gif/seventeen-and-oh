# Historical Scope Feasibility — 17-0

**Question asked:** what is the earliest NFL season from which 17-0 can include every
team, every roster, every relevant player, with *real* position-specific ratings good
enough for gameplay **and** simulation — no generic 67–71 mass fallback, with honest
confidence metadata?

**Method:** read-only probes over the actual pipeline files
(`data/processed/player_seasons.csv` — 96,167 rows; `data/processed/ratings.csv`;
`data/teams.csv`; `data/raw/rosters/*`). No guessing — every number below comes from
`reports/data_quality_by_year.csv` and `reports/position_rating_feasibility.csv`,
generated by `scripts/probe-data-quality.mjs` and `scripts/probe-position-feasibility.mjs`.

---

## Headline finding: two hard limits in the data

This dataset has **two independent ceilings**, and the answer is the intersection of both.

1. **TIME ceiling — performance stats begin in 1999.** Every box-score column
   (pass/rush/rec yards, receptions, passer rating, games_started) is **empty for
   1965–1998** and jumps to real coverage in 1999. The cliff is exact:

   | Season | stats_completeness | rating_confidence_avg | low_confidence% |
   |--------|-------------------:|----------------------:|----------------:|
   | 1996   | 1.9%               | 0.35                  | 97.5%           |
   | 1997   | 0.0%               | 0.34                  | 99.3%           |
   | 1998   | 0.0%               | 0.34                  | 99.3%           |
   | **1999** | **28.3%**        | **0.46**              | **72.4%**       |
   | 2000   | 27.6%              | 0.46                  | 73.5%           |
   | 2003   | 34.2%              | 0.53                  | 67.4%           |

2. **POSITION ceiling — only QB/RB/WR/TE ever get stats, in any era.** The defensive,
   offensive-line, kicking and punting stat columns are **empty in 100% of rows across
   all 60 seasons**. Peak evidence coverage ever recorded, per group:

   | Group | Peak evidence% | Year | | Group | Peak evidence% | Year |
   |-------|---------------:|------|-|-------|---------------:|------|
   | QB    | 85.1%          | 2022 | | EDGE  | 0.9%           | 1989 |
   | RB    | 93.4%          | 2015 | | DT    | 0.0%           | —    |
   | WR    | 91.4%          | 2015 | | LB    | 0.0%           | —    |
   | TE    | 90.0%          | 2009 | | CB    | 0.6%           | 2007 |
   | OT/OG/C | 0.0%         | —    | | S     | 2.7%           | 1972 |
   |       |                |      | | K / P | 3.3% / 5.0%    | 1972 |

   Verified by spot-check earlier in the investigation: T.J. Watt, Aaron Donald and Ray
   Lewis all carry **zero** defensive stats; Justin Tucker carries **zero** kicking
   stats. This is a structural gap in the source feed, not a sampling fluke.

**Consequence:** "full reliable ratings for every player on every roster" is **not
achievable in any season** from this data. Defense, the offensive line, and special
teams are *always* rated from role + bio (height/weight/depth/games), never from
production. The best honest state the data supports is: **evidence-graded skill
positions (QB/RB/WR/TE) + a sound role/bio model for everyone else, from 1999 on.**

What *is* complete in every era: **rosters and player IDs.** Roster completeness is
100% for essentially every season (the only dips — 1996–1998 at 96.8% — are the
historically-correct Cleveland Browns suspension, not missing data), and `player_id` is
100% populated across all eras. So the league can always be *fielded*; the open question
is purely **rating quality**, not coverage.

## Analysis by era

Roster coverage is ~100% in every era, so the differentiator is evidence and confidence.

| Era | Roster | Stats | Conf avg | low-conf% | needs-review% | Rateable positions | Verdict |
|-----|-------:|------:|---------:|----------:|--------------:|--------------------|---------|
| **1966–1977** | 100% | 0% | 0.34 | ~100% | ~6% | none from production; all role/bio | **Bio-only — legacy use** |
| **1978–1989** | 100% | 0% | 0.34–0.43 | ~99% | ~6% | none from production; all role/bio | **Bio-only — legacy use** |
| **1990–1998** | 100%* | 0% | 0.34 | ~99% | ~6% | none from production; all role/bio | **Bio-only — legacy use** |
| **1999–2010** | 100% | 28–35% | 0.46–0.54 | 66–74% | <1% | QB/RB/WR/TE graded; rest role/bio | **Usable — main pool** |
| **2011–2020** | 100% | 22–37% | 0.50–0.54 | 64–79% | <1% | QB/RB/WR/TE graded; rest role/bio | **Usable — main pool** |
| **2021–2024** | 100% | 25–26% | 0.51–0.52 | 75% | <1% | QB/RB/WR/TE graded; rest role/bio | **Usable — main pool** |

\* 1996–1998 show 96.8% — the Browns suspension, expected.

Notes that matter for "fair simulation":
- **Pre-1999 (1966–1998):** rosters are real and complete, but *no player has a single
  performance stat*. Star-vs-scrub separation is inferred from depth order, position and
  body type. That is exactly the condition that produced the 67–71 compression bug. It is
  playable as themed/throwback content, but it is **not evidence-fair** for a simulation
  that claims rating accuracy. ~99% of these players are low-confidence by the engine's
  own labelling.
- **1999–2001:** real skill-position stats arrive, but the league is 31 teams (Houston
  returns in 2002) and coverage is slightly thinner (~26–28%). Solidly usable.
- **2002–2015:** the strongest stretch — 32-team league, stats coverage peaks
  (32–37%), confidence 0.53–0.54. If you want the single best sub-range, it is here.
- **2016 onward:** still firmly usable, with a mild coverage dip (2016 = 21.7%); same
  tier, same shape (skill graded, rest role/bio).

## Rating quality tiers (what each year can actually earn)

- **Tier A — strong (evidence ratings for the whole roster):** **achievable in NO year.**
  Requires defensive/OL/ST production data that does not exist in any season.
- **Tier B — usable (graded skill core + disciplined role/bio elsewhere + honest
  confidence labels):** **1999 → present.** This is the realistic best case and the
  recommended bar for the "rated" game.
- **Tier C — weak (complete rosters, but every rating is a heuristic from depth/bio;
  ~99% low-confidence):** **1966 → 1998.** Playable as themed content; not evidence-fair.
- **Tier D — not acceptable (incomplete league / unusable):** none currently — rosters
  are complete in every era, so no year is Tier D on coverage grounds.

### Earliest acceptable year
- Earliest for **Tier A strong (full roster):** **none** — unsupported by the data.
- Earliest for **Tier A strong (skill positions only):** **1999.**
- Earliest for **Tier B usable:** **1999.**
- Earliest **technically possible but risky:** **1966** (rosters exist; ratings are
  bio/role heuristics, ~99% low-confidence).
- **Years needing manual review:** all of **1966–1998** if they are exposed as "rated"
  content; plus the defense/OL/K/P groups in *every* year if you want them evidence-backed
  (you cannot, from this feed — they stay role/bio + curated overrides).

## Root cause of the recent rating bugs

The reported symptoms — teams sitting in the 67–71 band (1992 Bills, 1999 Vikings, 2000
Dolphins, 1996 Jets, 1986 Bears, 1994 Cowboys, 1995 Steelers, 1988 Eagles) and the
alarming individuals (Keenum 90, Howell 91, Nelson 67, Watt 73) — map cleanly onto the
two ceilings above. Against the candidate causes you listed:

| Candidate cause | Verdict | Evidence |
|---|---|---|
| **Missing data** | ✅ **primary cause** | pre-1999 is bio-only (0% stats); defense/OL/K/P empty every era. The engine had no signal to separate players, so it parked them near the generic band. The 920 suspicious rosters from Phase 1 were **893 pre-1999 data-gap** + 27 modern. |
| **Too much scope** | ✅ **strategic root cause** | the DB spans 1965–2024, but only 1999+ has evidence and only for skill positions. Pulling 1966–1998 into a *rated* game forces the fallback that produced the 67–71 look. |
| **Bad fallback** | ⚠️ symptom, now mitigated | the old fallback collapsed unscored players onto 67–71; Phase 1 replaced it with role-based metadata. The *cause* underneath is still missing data. |
| **Bad position formulas** | ⚠️ minor, fixed | a few edge cases (K/P lockout, the 4 alarming players) were curated in Phase 1 (e.g. Watt 73→95, Howell 91→76). Not systemic. |
| **Bad joins / bad IDs / bad team-season mapping** | ❌ ruled out | `player_id` is 100% populated all eras; all 96,167 rows map to a team-season; rosters are 100% complete. |
| **Stale exports** | ❌ ruled out | full re-export completed in Phase 1 (0 FAIL on the distribution validator). |
| **Generation not processing full rosters** | ❌ ruled out | all 96,167 player-seasons carry a rating row. |

**One-line root cause:** the bugs are *scope exceeding evidence* — the database reaches
back to 1965, but the performance data needed to rate players honestly only exists from
1999, and even then only for QB/RB/WR/TE. Everything else falls to the fallback, which is
exactly what the 67–71 compression was.

## How to handle older (pre-1999) seasons

Recommended approach, in priority order:

1. **Modern as the main rated pool (1999+).** Make 1999–2024 the default, evidence-backed
   database the game rates and simulates against.
2. **Confidence labels surfaced in the UI.** The engine already emits
   `generated_high/medium/low_confidence` + `needs_manual_review`. Show them. A
   bio-only player should *look* bio-only to the user.
3. **Opt-in "Legacy / Throwback" pool for pre-1999**, clearly flagged as
   lower-confidence, kept **separate from** (not blended into) the rated modern pool.
4. **Curated famous teams via manual overrides + manual review**, added **gradually** —
   the '72 Dolphins, '85 Bears, etc. — rather than dumping all 909 bio-only team-seasons
   in at full confidence.
5. **Do not** present pre-1999 as "full historical coverage with accurate ratings." It is
   complete on rosters, heuristic on ratings.

A fully separate legends *database* is unnecessary — the override + confidence-label
machinery already in the pipeline does the job within one dataset.
